## 🚀 Featured Projects

### 📚 [BeReady](https://github.com/BraianGaspar/Beready_Projeto) — Language Learning Platform

> An interactive web platform for learning English through visual contextualization, gamified flashcards and quizzes.

| Layer | Stack |
|---|---|
| **Backend** | CakePHP 5 · PHP 8+ · REST API |
| **Frontend** | Vue.js 3 · TypeScript · Pinia · Vite |
| **Database** | PostgreSQL via Supabase (RLS enabled) |
| **Infra** | Docker · docker-compose |
| **Auth** | JWT with Access + Refresh tokens |
| **Access control** | RBAC with admin dashboard |

**Key decisions:** JWT refresh token rotation for security, Row Level Security on Supabase to enforce data isolation, full TypeScript on the frontend, Psalm for static analysis on the backend.
