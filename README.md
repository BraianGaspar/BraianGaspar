## 🚀 Featured Projects

### 📚 [BeReady](https://github.com/BraianGaspar/Beready_Projeto) — English Learning Platform

> Full stack web app for learning English through visual context: students create prompts that become translations, images and similar phrases, study with flashcards and quizzes, and track their progress on a dashboard. *Team project.*

| Layer | Stack |
|---|---|
| **Backend** | CakePHP 5 · PHP 8.2 · REST API (Services + Repositories) |
| **Frontend** | Vue.js 3 · TypeScript · Pinia · Vite · Tailwind CSS |
| **Database** | PostgreSQL · Supabase |
| **Auth** | JWT (Access + Refresh) · password recovery by email |
| **Access control** | RBAC with admin dashboard and statistics |
| **Infra & Quality** | Docker Compose · GitHub Actions (PHPUnit, PHPStan, PHPCS) · Sentry |

**Highlights:** layered API with interfaces for services and repositories, rate limiting middleware, image uploads with Cloudinary and error monitoring with Sentry.

---

### ❄️ [Efraim Ar-Condicionados](https://github.com/BraianGaspar/Efraim-ar-condicionado) — Air Conditioning Store

> Website and management system for an air conditioning store, with quote requests, user authentication and an admin panel for quotes, users and testimonials.

| Layer | Stack |
|---|---|
| **Frontend** | Next.js 14 (App Router) · TypeScript · Tailwind CSS |
| **Backend** | Node.js · TypeScript · Clean Architecture (domain, use cases, repositories) |
| **Database** | PostgreSQL · Supabase |
| **Security** | JWT · bcrypt · request validation · password recovery by email |

---

### 📨 [DLQ Auditor](https://github.com/BraianGaspar/DLQ-Auditor) — Dead Letter Queue Auditing Service

> Service that consumes failed messages from an AWS SQS Dead Letter Queue, classifies them by severity and persists them for analysis, removing them from the queue only after they are safely stored.

| Layer | Stack |
|---|---|
| **Backend** | Java · Spring Boot · Layered Architecture |
| **Messaging** | AWS SQS (DLQ) |
| **Database** | H2 (PostgreSQL mode) |
