- 🤖 **Atualmente** desenvolvendo soluções de IA e automações com Python, Node.js e OpenClaw

- 🗄️ **Trabalhando com** PostgreSQL e MySQL, com base sólida em PHP e Oracle SQL

- 🌐 **Inglês avançado** para documentação técnica e colaboração internacional
- ⚡ **O que me move:** transformar processos manuais e repetitivos em soluções automatizadas e bem organizadas

## 🚀 Projetos em Destaque

### 📚 [BeReady](https://github.com/BraianGaspar/Beready_Projeto) — Plataforma de Aprendizado de Inglês

> Aplicação web full stack para aprendizado de inglês por contextualização visual: o aluno cria prompts que viram traduções, imagens e frases semelhantes, estuda com flashcards e quizzes e acompanha sua evolução em um dashboard de progresso. *Projeto em equipe.*

| Camada | Tecnologias |
|---|---|
| **Back-end** | CakePHP 5 · PHP 8.2 · API REST (Services + Repositories) |
| **Front-end** | Vue.js 3 · TypeScript · Pinia · Vite · Tailwind CSS |
| **Banco de Dados** | PostgreSQL · Supabase |
| **Autenticação** | JWT (Access + Refresh) · recuperação de senha por e-mail |
| **Controle de acesso** | RBAC com painel administrativo e estatísticas |
| **Infra e Qualidade** | Docker Compose · GitHub Actions (PHPUnit, PHPStan, PHPCS) · Sentry |

**Destaques:** API em camadas com interfaces para services e repositories, middleware de rate limiting, upload de imagens com Cloudinary e monitoramento de erros com Sentry.

---

### ❄️ [Efraim Ar-Condicionados](https://github.com/BraianGaspar/Efraim-ar-condicionado) — Loja de Climatização

> Site e sistema de gestão para uma loja de ar-condicionados, com solicitação de orçamentos, autenticação de usuários e painel administrativo para orçamentos, usuários e depoimentos.

| Camada | Tecnologias |
|---|---|
| **Front-end** | Next.js 14 (App Router) · TypeScript · Tailwind CSS |
| **Back-end** | Node.js · TypeScript · Clean Architecture (domínio, casos de uso, repositórios) |
| **Banco de Dados** | PostgreSQL · Supabase |
| **Segurança** | JWT · bcrypt · validação de requisições · recuperação de senha por e-mail |

---

### 📨 [DLQ Auditor](https://github.com/BraianGaspar/DLQ-Auditor) — Serviço de Auditoria de Dead Letter Queue

> Serviço que consome mensagens com falha de uma Dead Letter Queue do AWS SQS, classifica por severidade e persiste para análise, removendo da fila somente depois de salvar com segurança.

| Camada | Tecnologias |
|---|---|
| **Back-end** | Java · Spring Boot · Arquitetura em Camadas |
| **Mensageria** | AWS SQS (DLQ) |
| **Banco de Dados** | H2 (modo PostgreSQL) |
